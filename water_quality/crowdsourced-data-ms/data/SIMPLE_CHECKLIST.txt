📝 TEST 1: CREATE OBSERVATION
================================================================================

□ 1. Open Postman application
□ 2. Click "New" button (top left)
□ 3. Click "HTTP Request"
□ 4. Click method dropdown (says "GET") → Select "POST"
□ 5. Click in URL box → Type: http://localhost:8081/api/observations
□ 6. Click "Headers" tab
□ 7. Click in "Key" box → Type: Content-Type
□ 8. Press Tab key → Type: application/json
□ 9. Click "Body" tab
□ 10. Click "raw" radio button
□ 11. Click "Text" dropdown → Select "JSON"
□ 12. Click in text area → Paste this:

{
  "citizenId": "C200",
  "postcode": "NE1 7ST",
  "temperature": 26.3,
  "ph": 7.2,
  "observations": ["Clear water"]
}

□ 13. Click "Send" button (top right)
□ 14. Check response shows "Status: 201 Created"
□ 15. Note the "id" number from response (e.g., "id": 1)

✅ TEST 1 COMPLETE!
