================================================================================
    HOW TO TEST CROWDSOURCED DATA MICROSERVICE IN POSTMAN - STEP BY STEP
================================================================================

📋 PREREQUISITES:
✅ Spring Boot application is running (check console for "Started on port 8081")
✅ MySQL database is running and connected
✅ Postman is installed and open

================================================================================
🎯 STEP 1: CREATE YOUR FIRST OBSERVATION (POST)
================================================================================

1. Open Postman
2. Click "New" → "HTTP Request"
3. Set method to: POST
4. Enter URL: http://localhost:8081/api/observations
5. Click "Headers" tab
6. Add header:
   - Key: Content-Type
   - Value: application/json
7. Click "Body" tab
8. Select "raw" radio button
9. Select "JSON" from dropdown (right side)
10. Paste this JSON:

{
  "citizenId": "C200",
  "postcode": "NE1 7ST",
  "temperature": 26.3,
  "ph": 7.2,
  "alkalinity": 8.5,
  "turbidity": 2.1,
  "observations": ["Clear water", "Good quality"],
  "imagePaths": ["image1.jpg", "image2.jpg"]
}

11. Click "Send" button
12. Check response:
    ✅ Status should be: 201 Created
    ✅ Response body should show the created observation with an ID
    ✅ "valid" field should be "true"
    ✅ "submittedAt" timestamp should be present

📝 NOTE THE ID from response (e.g., "id": 1) - you'll need it for GET by ID

================================================================================
🎯 STEP 2: GET ALL OBSERVATIONS (GET)
================================================================================

1. Create new request in Postman (or duplicate previous one)
2. Set method to: GET
3. Enter URL: http://localhost:8081/api/observations
4. No headers or body needed
5. Click "Send"
6. Check response:
   ✅ Status should be: 200 OK
   ✅ Response should be an array of all observations
   ✅ Should include the observation you just created

================================================================================
🎯 STEP 3: GET OBSERVATION BY ID (GET)
================================================================================

1. Create new request
2. Set method to: GET
3. Enter URL: http://localhost:8081/api/observations/1
   (Replace "1" with the actual ID from Step 1 response)
4. Click "Send"
5. Check response:
   ✅ Status should be: 200 OK
   ✅ Response should show single observation with that ID

TEST INVALID ID:
- URL: http://localhost:8081/api/observations/999
- Expected: 404 Not Found with error message

================================================================================
🎯 STEP 4: GET OBSERVATIONS BY CITIZEN ID (GET)
================================================================================

1. Create new request
2. Set method to: GET
3. Enter URL: http://localhost:8081/api/observations/citizen/C200
   (Replace "C200" with actual citizen ID)
4. Click "Send"
5. Check response:
   ✅ Status should be: 200 OK
   ✅ Response should be array of observations for that citizen

================================================================================
🎯 STEP 5: GET OBSERVATIONS BY POSTCODE (GET)
================================================================================

1. Create new request
2. Set method to: GET
3. Enter URL: http://localhost:8081/api/observations/postcode/NE1%207ST
   (Postman will auto-encode spaces, or manually use %20)
   Alternative: http://localhost:8081/api/observations/postcode/NE1 7ST
4. Click "Send"
5. Check response:
   ✅ Status should be: 200 OK
   ✅ Response should be array of observations for that postcode

================================================================================
🎯 STEP 6: TEST VALIDATION ERROR (POST - Invalid Data)
================================================================================

1. Create new request
2. Set method to: POST
3. Enter URL: http://localhost:8081/api/observations
4. Add header: Content-Type: application/json
5. In Body (raw, JSON), paste:

{
  "postcode": "NE1 7ST",
  "temperature": 26.3
}

(Note: Missing required field "citizenId")

6. Click "Send"
7. Check response:
   ✅ Status should be: 400 Bad Request
   ✅ Response should show validation error
   ✅ Error message should mention "Citizen ID is required"

================================================================================
💡 TIPS & TROUBLESHOOTING
================================================================================

❌ Connection Refused?
   → Check if Spring Boot app is running (look for "Started on port 8081" in console)

❌ Database Connection Error?
   → Check MySQL is running
   → Verify database "citizendb" exists
   → Check username/password in application.properties

❌ 404 Not Found?
   → Verify URL is correct
   → Check application is running
   → Verify endpoint path matches exactly

❌ 400 Bad Request?
   → Check JSON format is valid
   → Verify required fields are present (citizenId, postcode)
   → Check Content-Type header is set to application/json

❌ 500 Internal Server Error?
   → Check Spring Boot console for detailed error
   → Verify database connection
   → Check if tables are created

✅ Save Your Requests:
   → Create a Postman Collection
   → Save all requests for easy reuse
   → Import the provided POSTMAN_COLLECTION.json file

✅ Use Environment Variables:
   → Create Postman environment
   → Set variable: baseUrl = http://localhost:8081
   → Use {{baseUrl}}/api/observations in URLs
