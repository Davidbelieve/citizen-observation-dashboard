STEP-BY-STEP CLICKS:

1. CLICK "New" button (top left corner)
   → Location: Top left of Postman window
   → Look for: Blue button with "+ New" or "New" text

2. CLICK "HTTP Request" 
   → Location: Dropdown menu that appears after clicking "New"
   → Look for: "HTTP Request" option in the menu

3. CLICK on the method dropdown (says "GET" by default)
   → Location: Left side of URL bar
   → Look for: Dropdown showing "GET", "POST", etc.

4. CLICK "POST" from the dropdown
   → Location: Dropdown menu that opened
   → Look for: "POST" option in the list

5. CLICK in the URL input field
   → Location: Right side of the method dropdown
   → Look for: Empty text box next to "POST"

6. TYPE: http://localhost:8081/api/observations
   → Type exactly as shown (no spaces)

7. CLICK "Headers" tab
   → Location: Below URL bar
   → Look for: Tab labeled "Headers"

8. CLICK in "Key" column (first empty row)
   → Location: Headers section, left column
   → Look for: Empty cell under "Key"

9. TYPE: Content-Type
   → Type exactly as shown

10. PRESS Tab key on keyboard
    → This moves cursor to "Value" column

11. TYPE: application/json
    → Type exactly as shown

12. CLICK "Body" tab
    → Location: Next to "Headers" tab
    → Look for: Tab labeled "Body"

13. CLICK radio button next to "raw"
    → Location: Body tab section
    → Look for: Radio buttons (none, form-data, raw, etc.)
    → CLICK the circle next to "raw"

14. CLICK dropdown that says "Text" (right side)
    → Location: Right side of "raw" selection
    → Look for: Dropdown menu

15. CLICK "JSON" from dropdown
    → Location: Dropdown menu that opened
    → Look for: "JSON" option

16. CLICK in the large text area below
    → Location: Body section, large empty area
    → Look for: Big text box below the dropdowns

17. PASTE this JSON (or type it):
    {
      "citizenId": "C200",
      "postcode": "NE1 7ST",
      "temperature": 26.3,
      "ph": 7.2,
      "observations": ["Clear water"]
    }

18. CLICK "Send" button
    → Location: Top right corner of Postman
    → Look for: Blue button labeled "Send"
    → OR press Ctrl+Enter on keyboard

19. LOOK at bottom section (Response area)
    → Location: Bottom half of Postman window
    → Look for: Status code and response body
    → Should see: "Status: 201 Created" in green

✅ DONE! Observation created!

🔍 WHERE TO FIND THINGS IN POSTMAN
================================================================================

"New" Button:
→ Top left corner
→ Usually blue or gray button
→ Says "New" or has a "+" icon

Method Dropdown:
→ Left side of URL bar
→ Shows "GET", "POST", "PUT", etc.
→ Click to change method

URL Bar:
→ Right side of method dropdown
→ Long text input field
→ Where you type the URL

Tabs (Params, Headers, Body, etc.):
→ Below URL bar
→ Horizontal row of clickable tabs
→ Click to switch sections

Headers Section:
→ Appears when you click "Headers" tab
→ Has "Key" and "Value" columns
→ Where you add Content-Type header

Body Section:
→ Appears when you click "Body" tab
→ Has radio buttons (none, raw, etc.)
→ Has dropdown for format (Text, JSON, etc.)
→ Has large text area for data

Send Button:
→ Top right corner
→ Blue button
→ Says "Send"
→ Click to send request

Response Area:
→ Bottom half of Postman window
→ Appears after clicking Send
→ Shows status code, time, and response body
