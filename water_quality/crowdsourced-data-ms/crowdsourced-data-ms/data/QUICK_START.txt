           QUICK START - TEST YOUR API IN POSTMAN (5 MINUTES)
================================================================================

🎯 YOUR APPLICATION IS RUNNING ON: http://localhost:8081

================================================================================
STEP 1: CREATE FIRST OBSERVATION
================================================================================

1. Open Postman
2. Click "New" → "HTTP Request"
3. Method: POST
4. URL: http://localhost:8081/api/observations
5. Headers Tab → Add: Content-Type = application/json
6. Body Tab → Select "raw" → Select "JSON"
7. Paste this:

{
  "citizenId": "C200",
  "postcode": "NE1 7ST",
  "temperature": 26.3,
  "ph": 7.2,
  "observations": ["Clear water"]
}

8. Click "Send"
9. ✅ You should see: Status 201 Created with response containing id, valid: true

================================================================================
STEP 2: GET ALL OBSERVATIONS
================================================================================

1. New Request in Postman
2. Method: GET
3. URL: http://localhost:8081/api/observations
4. Click "Send"
5. ✅ You should see: Status 200 OK with array of observations

================================================================================
STEP 3: GET BY ID
================================================================================

1. New Request
2. Method: GET
3. URL: http://localhost:8081/api/observations/1
   (Use the ID from Step 1 response)
4. Click "Send"
5. ✅ You should see: Status 200 OK with single observation

================================================================================
STEP 4: GET BY CITIZEN ID
================================================================================

1. New Request
2. Method: GET
3. URL: http://localhost:8081/api/observations/citizen/C200
4. Click "Send"
5. ✅ You should see: Status 200 OK with array

================================================================================
STEP 5: GET BY POSTCODE
================================================================================

1. New Request
2. Method: GET
3. URL: http://localhost:8081/api/observations/postcode/NE1%207ST
   (or: NE1 7ST - Postman will encode it)
4. Click "Send"
5. ✅ You should see: Status 200 OK with array

================================================================================
ALL DONE! ✅
